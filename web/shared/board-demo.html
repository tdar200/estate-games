BOARD DEMO

Shared board API (web/shared/board.js, documented at the top of the file). Phones: new Board(el, { compact: true, youPlayerId }). Each phone loops a 7-square hop with board.hop(id, path, { follow: true }) (zoom 1.6× and pan, then ease out), the landing glow, dice and an event in the centre stage via setStage(). The first phone shows next-roll heat for "you" (highlightSquares(nextRollHeat(…).squares, "risk")). Tap any square to put its deed on the stage.
